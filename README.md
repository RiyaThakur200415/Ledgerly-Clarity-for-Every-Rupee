<h2>📌 1. Project Overview</h2>

<p>
  <strong>Ledgerly</strong> is a production-grade full-stack personal finance and
  expense tracking web application designed around a refined
  <strong>private-banking-inspired dashboard experience</strong>.
</p>

<p>
  The application combines warm ivory surfaces, deep forest accents, elegant
  serif typography, high-density financial data tables, interactive analytics,
  and Indian Rupee (₹) formatting into one focused financial workspace.
</p>

<blockquote>
  <strong>Ledgerly — Clarity for every rupee.</strong>
</blockquote>

<h2>⚡ 9. Getting Started</h2>

<h3>Prerequisites</h3>

<ul>
  <li>Node.js 18+</li>
  <li>npm or yarn</li>
  <li>Google Gemini API key</li>
</ul>

<h3>Step 1 — Clone the Repository</h3>

<pre>
git clone &lt;your-repository-url&gt;
cd Ledgerly-Clarity-for-every-rupee
</pre>

<h3>Step 2 — Install Dependencies</h3>

<pre>
npm install
</pre>

<h3>Step 3 — Configure Environment Variables</h3>

<p>Create a <code>.env</code> file in the root directory:</p>

<pre>
GEMINI_API_KEY=your_gemini_api_key
JWT_SECRET=your_jwt_secret
</pre>

<p>
  ⚠️ <strong>Never commit your .env file or expose API keys in a public repository.</strong>
</p>

<h3>Step 4 — Run in Development</h3>

<pre>
npm run dev
</pre>

<p>The application will be available at:</p>

<pre>
http://localhost:3000
</pre>

<h3>Step 5 — Build for Production</h3>

<pre>
npm run build
</pre>

<h3>Step 6 — Start Production Server</h3>

<pre>
npm start
</pre>
